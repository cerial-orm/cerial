# Cerial

A Prisma-like ORM for SurrealDB with schema-driven code generation and full TypeScript type safety.

## Get Started

- [Getting Started](/getting-started) — Installation, setup, first queries
- [Schema](/schema) — Define your data models
- [Relations](/relations) — Model relationships between tables
- [Queries](/queries) — Query methods: findOne, findMany, create, update, delete, upsert, count, exists
- [Transactions](/transactions) — Atomic batch execution with array, callback, and manual modes
- [Filtering](/filtering) — Comparison, string, array, and logical operators
- [Type System](/types) — CerialId, NONE vs null, generated types
