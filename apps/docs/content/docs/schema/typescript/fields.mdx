A field is a key in the object you pass to `model` or `object`, and its value is a builder from `f`. The type comes from the factory (`f.string()`), and everything else is a method chained onto it. Each call returns a new builder, so a partial chain can be stored in a const and reused.

## Field types

Each type has a factory with the same name.

```cerial
model Scalars {
  id Record @id
  name String
  contact Email
  count Int
  ratio Float
  amount Number
  active Bool
  born Date
  token Uuid
  ttl Duration
  price Decimal
  blob Bytes
  area Geometry
  payload Any
}
```

```typescript
import { f, model } from 'cerial/schema';

export const Scalars = model('Scalars', {
  id: f.record().id(),
  name: f.string(),
  contact: f.email(),
  count: f.int(),
  ratio: f.float(),
  amount: f.number(),
  active: f.bool(),
  born: f.date(),
  token: f.uuid(),
  ttl: f.duration(),
  price: f.decimal(),
  blob: f.bytes(),
  area: f.geometry(),
  payload: f.any(),
});
```

`f.record()` takes the id type and is covered on [Models](/schema/typescript/models). `f.object`, `f.tuple`, `f.literal` and `f.enum` reference your own types and are covered on [Objects and tuples](/schema/typescript/objects-tuples) and [Enums and literals](/schema/typescript/enums-literals). `f.relation` and `f.reverse` are covered on [Relations](/schema/typescript/relations).

## Modifiers

`?`, `[]` and `!!private` are methods too: `.optional()`, `.array()` and `.private()`. `@nullable` is `.nullable()`. A field that is both optional and nullable chains both.

```cerial
model Modifiers {
  id Record @id
  nickname String?
  middleName String? @nullable
  tags String[]
  secret String !!private
}
```

```typescript
import { f, model } from 'cerial/schema';

export const Modifiers = model('Modifiers', {
  id: f.record().id(),
  nickname: f.string().optional(),
  middleName: f.string().optional().nullable(),
  tags: f.string().array(),
  secret: f.string().private(),
});
```

`.array()` works on every type:

```cerial
model Lists {
  id Record @id
  names String[]
  contacts Email[]
  counts Int[]
  ratios Float[]
  amounts Number[]
  flags Bool[]
  dates Date[]
  tokens Uuid[]
  spans Duration[]
  prices Decimal[]
  blobs Bytes[]
  shapes Geometry[]
  anything Any[]
}
```

```typescript
import { f, model } from 'cerial/schema';

export const Lists = model('Lists', {
  id: f.record().id(),
  names: f.string().array(),
  contacts: f.email().array(),
  counts: f.int().array(),
  ratios: f.float().array(),
  amounts: f.number().array(),
  flags: f.bool().array(),
  dates: f.date().array(),
  tokens: f.uuid().array(),
  spans: f.duration().array(),
  prices: f.decimal().array(),
  blobs: f.bytes().array(),
  shapes: f.geometry().array(),
  anything: f.any().array(),
});
```

`Any` accepts NONE and null already, so `f.any()` has no `.optional()` or `.nullable()`:

```typescript
import { f, model } from 'cerial/schema';

export const Loose = model('Loose', {
  id: f.record().id(),
  // @ts-expect-error Any already accepts NONE and null
  maybe: f.any().optional(),
});
```

## Decorators

Every field decorator is a method named after the decorator, without the `@`. Arguments become call arguments.

```cerial
model Decorated {
  id Record @id
  email Email @unique
  handle String @index
  role String @default('user')
  visits Int @defaultAlways(0)
  createdAt Date @createdAt
  updatedAt Date @updatedAt
  seenAt Date @now
  ttl Duration @default(1h)
  code String @readonly
}
```

```typescript
import { f, model } from 'cerial/schema';

export const Decorated = model('Decorated', {
  id: f.record().id(),
  email: f.email().unique(),
  handle: f.string().index(),
  role: f.string().default('user'),
  visits: f.int().defaultAlways(0),
  createdAt: f.date().createdAt(),
  updatedAt: f.date().updatedAt(),
  seenAt: f.date().now(),
  ttl: f.duration().default('1h'),
  code: f.string().readonly(),
});
```

`.default()` and `.defaultAlways()` take a boolean, `null`, a number or a string. A duration is written as a string.

### Generated ids

`.uuid()`, `.uuid4()` and `.uuid7()` generate a value when none is given.

```cerial
model Tokens {
  id Record @id
  anyId Uuid @uuid
  randomId Uuid @uuid4
  sortableId Uuid @uuid7
}
```

```typescript
import { f, model } from 'cerial/schema';

export const Tokens = model('Tokens', {
  id: f.record().id(),
  anyId: f.uuid().uuid(),
  randomId: f.uuid().uuid4(),
  sortableId: f.uuid().uuid7(),
});
```

A field takes one auto-generation decorator. Once you chain one, the others are no longer methods on the builder:

```typescript
import { f, model } from 'cerial/schema';

export const Clash = model('Clash', {
  id: f.record().id(),
  // @ts-expect-error uuid cannot be combined with default
  token: f.uuid().uuid().default('fixed'),
});
```

### Array decorators

```cerial
model Collections {
  id Record @id
  scores Int[] @sort
  recent Date[] @sort(false)
  labels String[] @distinct
  members String[] @set
}
```

```typescript
import { f, model } from 'cerial/schema';

export const Collections = model('Collections', {
  id: f.record().id(),
  scores: f.int().array().sort(),
  recent: f.date().array().sort('false'),
  labels: f.string().array().distinct(),
  members: f.string().array().set(),
});
```

`.sort()` takes `'asc'`, `'desc'`, `'true'` or `'false'`, as strings. `@sort(false)` is `.sort('false')`.

### Geometry subtypes

A geometry field narrows with a subtype method. Chain several to allow several subtypes.

```cerial
model Places {
  id Record @id
  spot Geometry @point
  route Geometry @line
  zone Geometry @polygon
  spots Geometry @multipoint
  routes Geometry @multiline
  zones Geometry @multipolygon
  mixed Geometry @geoCollection
  either Geometry @point @polygon
}
```

```typescript
import { f, model } from 'cerial/schema';

export const Places = model('Places', {
  id: f.record().id(),
  spot: f.geometry().point(),
  route: f.geometry().line(),
  zone: f.geometry().polygon(),
  spots: f.geometry().multipoint(),
  routes: f.geometry().multiline(),
  zones: f.geometry().multipolygon(),
  mixed: f.geometry().geoCollection(),
  either: f.geometry().point().polygon(),
});
```
