## 0.2.0

**SurrealDB compatibility:** 3.1.5 | **SDK:** surrealdb 2.0.4

This minor release moves Cerial's supported SurrealDB target to 3.1.5 and upgrades the bundled SurrealDB SDK.

### Changed

- Upgraded the bundled SurrealDB JavaScript SDK (`surrealdb`) from 2.0.0 to 2.0.4.
- Updated the supported SurrealDB version to 3.1.5. The full test suite passes against this version; see the SurrealDB Compatibility page for the matrix. Cerial 0.1.x remains supported for SurrealDB 3.0.1 – 3.0.4.
